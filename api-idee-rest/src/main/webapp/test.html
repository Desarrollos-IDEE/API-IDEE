GALERÍA DE PLUGINS

CONTROLES

[attributions]

attributions

Muestra los créditos y la autoría de las fuentes de datos cartográficos utilizadas en el mapa actual.

[backgroundlayers]

backgroundlayers

Permite al usuario alternar entre diferentes mapas base, como ortofotos, mapas físicos o capas de relieve.

[getfeatureinfo]

getfeatureinfo

Herramienta para consultar información detallada de los elementos al hacer clic sobre las capas activas del mapa.

[implementationswitcher]

implementationswitcher

Selector para cambiar rápidamente entre diferentes bibliotecas de visualización de mapas (como OpenLayers o Leaflet).

[location]

location

Muestra las coordenadas geográficas exactas de la posición del cursor o del centro del mapa en tiempo real.

[measurebar]

measurebar

Herramienta de medición de áreas y distancias.

[overviewmap]

overviewmap

Muestra un minimapa interactivo

[panzoom]

panzoom

Botones básicos de navegación que permiten desplazarse por el mapa y acercar o alejar la visualización (zoom).

[panzoombar]

panzoombar

Barra deslizante que ofrece un control preciso y visual del nivel de escala o zoom del mapa.

[rotate]

rotate

Control que permite girar la orientación del mapa para visualizarlo desde diferentes ángulos cardinales.

[scale]

scale

Representación numérica de la relación entre las unidades en el mapa y la distancia real en el terreno.

[scaleline]

scaleline

Barra gráfica dinámica que indica la escala visual para medir distancias aproximadas directamente sobre el mapa.

[timeline]

timeline

Permite visualizar y navegar a través de series temporales de datos, mostrando la evolución del mapa en distintas fechas.

[wmcselector]

wmcselector

Selector de contextos WMC (Web Map Context) que permite cambiar entre distintos mapas guardados, restaurando capas, estilos y extensión.
