Rampa de colores

IDEE.style.Raster

Rampa: simbología por valores. Filtros: ajustes sobre el color nativo.

formula

Sin fórmula: una banda o media. NDVI [nir, red]; NDWI [green, nir]; NBR [nir, swir].

bands

Un número para una banda; varios separados por coma para media.

Rango

Rango de datos de la rampa (0–1 con normalize; índices típico −1…1).

Avanzado

Rango OpenLayers: 0 o mayor. Valor 1 = sin corrección.

Rango OpenLayers: -1 a 1. 0 = sin cambio, -1 = escala de grises.

Rango OpenLayers: -1 a 1. 0 = sin cambio. Ajusta la exposición sobre el color de la capa.

Rango OpenLayers: -1 a 1. 0 = sin cambio. Ajusta el contraste sobre el color de la capa.

Rango OpenLayers: -1 a 1. 0 = sin cambio. Ajusta el brillo sobre el color de la capa.

Vacío: no se añade al estilo. Con valor (p. ej. 0): esos píxeles serán transparentes.

Serialización

Usa style.serialize() → base64. Al aplicar se deserializa con setStyle(string).
