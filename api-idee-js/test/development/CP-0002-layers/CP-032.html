CP-032: intervalo de una capa

Motor activo:

«Sin intervalo» omite el parámetro; «Intervalo 0» envía refreshInterval: 0. En este mapa sin intervalo global, ninguno activa el autorefresco. El campo de milisegundos solo se usa con «Solo refreshInterval».

Arranca servidor-autorefresco.py en 8083. El formulario crea un mapa nuevo; el autorefresco conserva el mapa.

En Red filtra por _ideeRefresh. Consola: mapa y capa.
