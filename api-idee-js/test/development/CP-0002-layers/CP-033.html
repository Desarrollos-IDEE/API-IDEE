CP-033: intervalo del mapa

Motor activo:

El intervalo válido del mapa sobrescribe el de cada capa. Si el mapa no tiene intervalo, la capa utiliza el último valor que tenga configurado. Retirar y reinsertar conserva ese valor. «Actualizar intervalo del mapa » cambia todas las capas sin recrear el mapa; si se elige «Sin intervalo» o «Intervalo 0», desactiva su autorefresco. El estado muestra el intervalo configurado, también cuando la capa está retirada. El mapa inicial contiene WMS, GeoJSON, KMZ y XYZ. Los grupos solo contienen capas.

Arranca servidor-autorefresco.py en 8083. En Red filtra por _ideeRefresh. El mapa conserva el mismo contenedor. Consola: mapa, capas.
