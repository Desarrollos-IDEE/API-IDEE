CP-035: GPX desde JSON con estilo IDEE

Puntos, ruta y track con dos segmentos. Consola: mapa y capa.

El estilo inicial procede del JSON. La segunda opción aplica una instancia que hereda de IDEE.Style. Comprueba colores y tamaños, estiloIDEE: true y su conservación al recargar.
